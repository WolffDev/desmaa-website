# Public Assets

This directory contains static assets that will be served directly.

## Required PWA Icons

To enable full PWA functionality, add the following icon files:

1. **icon-192.png** - 192x192px PNG icon
   - Used for Android home screen and app drawer
   - Should be a square icon with your app logo

2. **icon-512.png** - 512x512px PNG icon
   - Used for splash screens and larger displays
   - Should be a square icon with your app logo

3. **favicon.ico** - Standard favicon
   - 16x16, 32x32, or multi-size ICO file
   - Shown in browser tabs

4. **apple-touch-icon.png** - 180x180px PNG
   - Used when users add to iOS home screen
   - Should be a square icon with your app logo

## Recommended Sizes

- 192x192 (required for PWA)
- 512x512 (required for PWA)
- 180x180 (apple-touch-icon)
- 32x32 (favicon)
- 16x16 (favicon)

## Tools for Creating Icons

- [RealFaviconGenerator](https://realfavicongenerator.net/)
- [PWA Asset Generator](https://github.com/onderceylan/pwa-asset-generator)
- [Favicon.io](https://favicon.io/)

## Image Guidelines

- Use a simple, recognizable logo or icon
- Ensure good contrast for visibility
- Test icons on both light and dark backgrounds
- Icons should work at small sizes (16x16)
